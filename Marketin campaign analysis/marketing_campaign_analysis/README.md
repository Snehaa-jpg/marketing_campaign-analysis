# marketing_campaign_analysis
Marketing Campaign Analytics & A/B Testing Overview  This project analyzes customer marketing campaign data to understand spending behavior, evaluate campaign effectiveness, and generate actionable business insights using statistical analysis and machine learning.  Objectives Analyze customer demographics and purchasing patterns Measure marketing campaign effectiveness Perform A/B testing and hypothesis testing Predict customer spending behavior using machine learning Generate data-driven business recommendations Technologies Used Python Pandas NumPy Matplotlib SciPy Scikit-learn SQL Key Features Data Cleaning & Feature Engineering Handled missing values Created business metrics such as TotalSpend and Age Prepared data for analysis and modeling Exploratory Data Analysis Analyzed customer demographics Investigated spending patterns across customer segments Visualized campaign performance and purchasing behavior A/B Testing Conducted hypothesis testing using SciPy Evaluated the effectiveness of marketing campaigns Identified statistically significant differences in customer spending Machine Learning Built a Multiple Linear Regression model Predicted customer spending using income and purchase behavior metrics Achieved an R² score of 0.73 SQL Analytics Developed SQL queries for customer segmentation Analyzed campaign acceptance and spending behavior Generated business-oriented reports Key Insights Campaign 1 had a statistically significant impact on customer spending. Customer income and purchase activity strongly influence spending behavior. Highly engaged customers contribute significantly to revenue generation. Customer segmentation can improve campaign targeting and marketing ROI. Business Recommendations Focus marketing efforts on high-income and highly engaged customers. Use customer segmentation to personalize campaign strategies. Leverage purchasing behavior metrics to improve targeting accuracy. Continuously evaluate campaign performance using statistical testing.
