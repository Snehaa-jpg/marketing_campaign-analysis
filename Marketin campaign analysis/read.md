# Marketing Campaign Analytics & A/B Testing

## Project Overview

This project analyzes customer marketing campaign data to evaluate campaign effectiveness, customer behavior, and spending patterns.

## Tools Used

* Python
* Pandas
* NumPy
* SciPy
* Scikit-learn
* SQL
* Matplotlib

## Key Analyses

### Data Cleaning

* Handled missing values
* Created new business metrics

### Campaign Analysis

* Evaluated campaign acceptance rates
* Compared campaign performance

### A/B Testing

* Performed hypothesis testing using SciPy
* Found statistically significant differences between customer groups

### Regression Modeling

* Built Multiple Linear Regression model
* Achieved R² Score of 0.731

### Customer Segmentation

* Analyzed spending patterns by education and marital status

### SQL Analysis

* Customer segmentation queries
* Campaign performance queries
* Spending behavior analysis

## Business Insights

* Campaign 1 demonstrated significant impact on customer spending.
* Income and purchasing behavior are strong predictors of customer expenditure.
* Highly engaged customers generate greater revenue and should be prioritized in marketing strategies.
